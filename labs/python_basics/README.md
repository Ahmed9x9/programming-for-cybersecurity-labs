# Python basics

This topic covers the introductory scripting exercises: shared assignment, string replacement,
suffix repetition, number formatting, degree conversion, university email construction, basic
password-policy checks, and service-to-port output.

```bash
python -m labs.python_basics.solutions --first-name Ahmed --last-name Al-Shaikh
```

All reusable functions validate their inputs and return values; only the command-line demonstration
prints output.
